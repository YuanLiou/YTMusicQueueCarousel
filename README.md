### How to install a Work-in-progress version?

1. You can install from the source code. First Click 'Code' Button then click 'Download ZIP'

<img width="60%" alt="Step001" src="https://github.com/user-attachments/assets/60150aa2-2afd-4906-a0bb-e246c1dcd947" />

2. Extract the ZIP file you download.

<img width="60%" alt="Step002" src="https://github.com/user-attachments/assets/832263ce-761d-4970-ab35-bc243eb3f013" />

3. Open Chrome browser (or other browser based on Chrome, e.g. Edge, Brave, Vivaldi, Dia, Arc...), Open your extension manage page.

4. Enable 'Developer Mode' and click the Load unpacked.

<img width="60%" alt="Step003" src="https://github.com/user-attachments/assets/8c752193-766b-4150-abea-2adb9499dafc" />

5. Select the folder that extracted aboves. You are now installed the extension.

<img width="60%" alt="Step004" src="https://github.com/user-attachments/assets/9ce65d2c-fb32-4943-b7c1-b448eabadb4b" />
